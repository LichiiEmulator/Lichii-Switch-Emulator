**Lichii Switch 2 Emulator** build 75 is lichii nx2 from https://github.com/zortos293/Lichii. Aka lichii github and lichii 22.1.8. Games, keys, and firmware are not included.

## Getting Started
1. Extract the archive and run lichii.exe.
2. Point it at keys, firmware, and a game you already own.
3. The updater rail pulls the next build.
4. Notes in `files/notes/`.
